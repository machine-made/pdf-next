About

          

            
            pdf-next by machine-made

          

          
A PDF, image and Markdown viewer for the compile loop, made in the machine-made lab. MIT licence.

          

            Details: what pdf-next is built with
            

              
App shell

              
Rust and Tauri 2 (window, installers), with the system webview: WebView2, WKWebView or WebKitGTK. serde, sha2, tempfile and cap-std keep the review file and edits safe.

              
PDF

              
Mozilla PDF.js 6.3.289 renders and searches. lopdf and picamatl (pure Rust) make Reduce PDF. SyncTeX hints use the synctex program of your TeX install, when present.

              
Markdown

              
pulldown-cmark parses, ammonia sanitizes, highlight.js 11.12 colours code.

              
Reviews

              
diff-match-patch 1.0.5 (Google) shows what an agent changed, word by word.

              
TeX equations

              
math-core 0.9 turns TeX into MathML, set in New Computer Modern Math.

              
Panes

              
dockview 8.8 lays out the tiles and their tabs.

              
Fonts

              
Latin Modern Roman; machine-made Weft, Sans and Heddle 0.1; Monaspace 1.400 (GitHub Next).

              
Licences

              
pdf-next is MIT. PDF.js Apache-2.0; Tauri, serde and most crates MIT or Apache-2.0; highlight.js BSD-3; diff-match-patch Apache-2.0; dockview MIT; fonts GUST and SIL OFL. Full list in the README.
